# The Agency AI Install: Choose Your Starter File

This is the original shared starter-pack download. It now includes starter files for both workshop tracks.

## Choose one platform file

- Using Claude? Keep `CLAUDE-STARTER.md` and ignore `AGENTS-STARTER.md`.
- Using Codex? Keep `AGENTS-STARTER.md` and ignore `CLAUDE-STARTER.md`.

Do not rename or fill in your selected starter file during pre-work. It becomes `CLAUDE.md` or `AGENTS.md` during Phase 7 of the workshop.

## Four starter-pack setup steps

1. Create `MY BIZ BRAIN` on your computer if you have not already.
2. Copy this pack into it, keeping the `memory` and `current-projects` folders intact.
3. Add your gathered materials. A `gathered-materials` folder is fine. Use actual files for writing samples, team, projects, and agency facts. For paid tools, make one simple list; screenshots are not needed.
4. Open `MY BIZ BRAIN` in Cowork or Codex once and make sure the files appear.

These are the four starter-pack setup steps, not the full readiness checklist. Continue on the correct pre-work page and complete all six checks under **Final check**:

- [Claude pre-work](https://standardplaybook.com/aiinstall/prework/claude)
- [Codex pre-work](https://standardplaybook.com/aiinstall/prework/codex)
